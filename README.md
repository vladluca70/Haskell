# 🧑‍💻 Learning Haskell – Functional Programming Journey

This repository showcases my self-study progress in **Haskell**, a purely functional programming language that fascinated me due to its elegance and power.

## 🚀 Getting Started

I began with simple exercises to grasp the basics of Haskell’s syntax and functional style:

- Summing two numbers  
- Summing three numbers  
- Multiplying two numbers  
- Computing factorial  
- Calculating Gauss sum  

## 🔧 Core Concepts Explored

Once comfortable with basics, I moved on to creating functions for:

- Checking if a number is even  
- Checking if a number is prime  

I also dived into **lists**, using list comprehensions like:

```haskell
n = [x | x <- [1..n], n `mod` x == 0]
```

and important keywords like `map` and `filter`.

## 🌟 Advanced Functional Constructs

- Generating the Fibonacci sequence  
- Creating trees (arbors)  
- Implementing the Greatest Common Divisor (GCD) function  

Combining these concepts allowed me to build more complex and interesting functions.

## 🖥 Environment

I worked primarily in a **Linux terminal**, compiling and running Haskell files using the appropriate commands after saving the source code.

## 💡 Final Thoughts

Learning Haskell has expanded my understanding of functional programming paradigms and helped me appreciate concise and expressive code. This repository reflects my growing comfort with Haskell and my enthusiasm for exploring its unique features.
